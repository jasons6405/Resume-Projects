It is a compilation implementations of every data structure and algorithm covered in the class, as well as a program that makes use of each of them.
Skeleton code was written by the instructor and TAs, everything else was written by me.


The TrailManager folder contains a project from my Data Structures & Algorithms class.
This project focused on creating and using a simple UI for a program that manages trails and distances between landmarks.
Some skeleton code was written by TAs, everything else was written by me.

The CSC433 Final Report pdf is the final report written by me and a team of 3 others as part of the semester project for my Privacy in the Modern Age class.
The report details our findings about airport biometric usage and security, as well as ways it could be improved. 
Our proposed solution for the report was to use computer vision to blur faces and remove PII from recordings.

The rlc.S file contains a project written for my Computer Organization & Assembly class.
The project is written using Assembly language, and implements run-length compression on dynamic memory buffers.
The project was entirely written by me.
